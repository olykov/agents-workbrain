# Security Policy Reference

This file mirrors the canonical repo policy in `01_knowledge_base/00_system/security_policy.md`.

Use `01_knowledge_base/00_system/security_policy.md` first when available.

## Hard Rules

- Default to dry-run.
- Do not delete files.
- Do not overwrite files.
- Do not edit raw source files.
- Do not move files outside the vault.
- Do not expose secrets in routing plans.
- Stop on suspected secrets and ask the user.
